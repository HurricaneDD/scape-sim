风光摄影 模拟器

一个基于CesiumJS的工具，用于模拟在地球上实景的风光摄影。

以便于摄影者提前了解风景、太阳光线情况、估算所需焦段。

灵感来源于APP"极摄"。

横屏版适用于电脑、平板 竖屏版适用于手机
常见问题 更新日志 Github
